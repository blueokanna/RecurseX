# 刷新模型与依赖概率界

版本：**0.2.6**。本页替换旧版的最弱依赖与共轭后验论证。

## 观测对象

成功刷新后，解析器比较 RRset 的规范化内容。TTL 与 RRSIG 轮换不算内容变化；
比较使用排序后的完整记录，不再仅凭非密码学指纹判等。
观测包含间隔 `h` 和两端内容是否不同的二元值 `Y`，并不包含期间的变化次数。
A → B → A 在这种采样中不可见。

如果假设变化服从不回退的泊松过程，二元区间观测的似然为：

```
L(lambda) = product((1-exp(-lambda*h_i))^Y_i * exp(-lambda*h_i*(1-Y_i)))
```

存在 `Y_i=1` 时，Gamma 先验一般不与这个似然共轭。实现中的
`alpha += w*Y; beta += w*h` 是借鉴计数模型的工程近似，不是精确后验。
在上述理想似然中，未变化观测同样提供信息；旧文档中“未变化不提供信息”的说法不成立。
对任意 DNS 更新过程，目前没有证明这种近似的误差大小及方向。

遗忘使证据向基于 TTL 的先验衰减。权重与证据上限限制历史影响，不能检测伪造观测，
也不能证明先验符合现实。TTL 是缓存有效期，不是实测变化率。
Gamma 的任意正形状参数在正速率参数下都有有限均值；默认形状 1 是工程选择。

## Gamma 计算能够证明什么

在选定的分布 `Lambda ~ Gamma(alpha,beta)` 内，对 `x >= alpha/beta`：

```
Pr(Lambda >= x) <= exp(alpha-beta*x) * (beta*x/alpha)^alpha
```

实现用 Chernoff 表达式求单侧界，再计算 `p_i = exp(-lambda_hi*age)`。
这是模型内结论，不是实际 DNS 过程的覆盖率证明，更不是数据或上游身份的认证。
均值校准良好也不能代替尾部覆盖率验证。

## 依赖聚合

仅当各 `p_i` 确实是事件 `E_i` 的有效边缘概率下界时，union bound 给出：

```
Pr(all E_i) >= max(0, 1 - sum(1-p_i))
```

不需要独立性假设，但有效边缘界这个前提不能省略。聚合预测不会自动建立模型尚未证明的覆盖率。
`min(p_i)` 不是交集概率的一般下界：两个 0.99 的边缘概率，在错误事件互斥时联合概率只有 0.98。
直接相乘则需要独立性。

`joint_lower_bound()` 使用上述 union bound。`bound()` 的最小值仅作诊断；
`independent_bound()` 只是保留成员的乘积，不包括被容量限制省略的成员，不能作为放行依据。
非有限成员值按零处理，非法阈值不允许过期放行。

容量限制之外的依赖仍以固定大小的摘要保留失败概率质量、最高后果等级和禁止过期标记。
容量为零也不能丢掉 DNSSEC 证明依赖的禁用条件。摘要是保守的；丢弃身份之后无法再逐项去重或刷新它们。

## 刷新收益

设 `L=max(0,1-S)`、`S=sum(1-p_i)`，假设把成员 `j` 刷新到 1：

```
gain_j = max(0, 1 - (S - (1-p_j))) - L
```

刷新非最弱成员也可能提高整体界。当失败质量超过 1 时，可能需要刷新多个成员，整体界才变正。
即时收益为零不代表该成员无关。`refresh_plan` 按收益排序并确定性处理并列；
这不是有限多步预算下全局最优调度的证明。

信息价值调度通过真实刷新使用的同一 `observe` 函数模拟两种结果，再按模型期望收益排序、
为各后果等级保留名额。它不会把预测升级为安全事实。

## 过期服务策略

默认 `PlannerConfig::stale_policy = Disabled`。`OnRefreshFailure` 要求本次请求已经访问上游失败，
才继续检查年龄、证据量、后果等级、依赖界与总风险预算。`ImmediateExperimental` 是显式实验选项。
JSON 在顶层 `stalePolicy` 下使用 `disabled`、`on-refresh-failure`、`immediate-experimental`。

`V*(1-p)*C*kappa` 是工程策略评分，给它设预算不等于证明现实错误率。
DNSSEC 证明依赖禁止过期服务；无效签名在缓存准入和重用时均被拒绝。
过期响应使用配置的正 TTL，默认 30 秒，且不置 AD。
参见 [RFC 8767](https://www.rfc-editor.org/rfc/rfc8767)。

## 尚需完成的实证验证

`content_calibration()` 将成功刷新前的预测与之后的端点内容比较，失败刷新不算“未变化”。
调度策略会带来样本选择偏差。真实覆盖率验证需要独立采样轨迹、带时间戳的权威真值、
回退与突发更新过程、失败截尾分析和样本外区间。
0.2.6 不声称已有这类公网覆盖率结果。公式与本地回归测试验证实现一致性，不证明数据真实、
网络永远可达或采样间内容一直正确。
